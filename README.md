# 🧠 ContractLens AI

**ContractLens AI** is an intelligent web application built with **Streamlit** that automatically summarizes and analyzes contract documents.  
It uses **Natural Language Processing (NLP)** and **Transformer-based models** to extract key insights from lengthy contracts, saving time and improving comprehension.

---

## 🚀 Features

- 📄 Upload contract text or PDF files
- 🧩 AI-powered summarization and key point extraction
- 🗂️ Clause and term identification
- ⚙️ User-friendly Streamlit interface
- 🔒 Secure and local text processing

---

## 🛠️ Tech Stack

- **Python 3.x**
- **Streamlit**
- **Transformers (Hugging Face)**
- **PyTorch**
- **NumPy, Pandas**
- **scikit-learn**
